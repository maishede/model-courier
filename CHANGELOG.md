# Changelog

## 0.1.0 - 2026-09-18

Initial public MVP:

- versioned image and audio task contracts;
- FastAPI control plane with SQLite WAL and filesystem artifacts;
- lease-safe queueing, retries, quotas, cancellation, and cleanup;
- outbound Worker runtime with heartbeat and process-level timeouts;
- Mock Provider plus optional Faster-Whisper, FunASR, and Ultralytics adapters;
- Python device SDK, REST protocol documentation, deployment examples, and CI.
